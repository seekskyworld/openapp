# Code of Conduct

OpenApp is a public project for people building and operating self-hosted
applications. Participants are expected to be respectful, specific and
collaborative.

Maintainers will address harassment, discrimination, threats, doxxing,
deliberate disclosure of credentials or private deployment information, and
repeated disruptive behavior. Technical disagreement is welcome when it focuses
on the problem, evidence and trade-offs.

Report conduct concerns privately through the security contact in
[SECURITY.md](SECURITY.md), or contact a repository maintainer directly. Do not
include passwords, database dumps, personal data or exploit details in a public
issue.
