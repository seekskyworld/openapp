# Support

Use repository issues for reproducible bugs and feature requests. Include the OpenApp version, release fingerprint, Node/Docker/PostgreSQL versions, whether the deployment is Core-only or composed, and sanitized steps/logs. Include Adapter versions for composed deployments.

Core issues cover contracts, authentication infrastructure, tenant permissions, orchestration and generic deployment. Application-specific login rules, runtime images and historical data handling belong in the responsible Adapter's issue tracker.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). Do not attach real database dumps, Volume archives, credentials or personal account details. Community support is best-effort, with no uptime or response SLA.
